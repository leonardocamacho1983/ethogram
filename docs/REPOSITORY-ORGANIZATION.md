# Repository organization audit

## Current boundaries

- `packages/agentbook/` is the publishable `@ethogram/core` package. Its directory name is an internal legacy detail.
- `packages/cli/` is the publishable CLI and the authoritative alpha developer runtime. It owns `ethogram init`, `ethogram dev`, project loading, evaluation, hot reload, stale-evidence protection, and the read-only browser UI.
- `app/`, `lib/agentbook/`, and `stories/` are the original root Next.js prototype and the executable harness behind Tests 01–05. They are not the packaged CLI runtime.
- `tests/01-*.md` through `tests/09-*.md` are frozen historical records. Executable files beside them continue to validate the architecture.
- The CLI-generated Access Request project is the canonical public new-project example. Test 08 is the source for the existing-agent guide; Test 09 is the source for the framework-owned evidence guide.

## External-developer confusion risks

1. The root Next.js prototype looks like the product even though the packaged CLI is authoritative.
2. `packages/agentbook/` retains the codename as an internal directory, though its package identity is `@ethogram/core`.
3. Both `package-lock.json` and `pnpm-lock.yaml` exist; npm is the tested release path and both lockfiles are regenerated for the alpha.
4. Root demo Stories duplicate concepts now generated by the CLI.
5. Generic v0/shadcn scaffold artifacts remain tracked even though the current app does not use them.

## Proposed cleaned structure

```text
ethogram/
├── packages/
│   ├── core/                 # @ethogram/core
│   └── cli/                  # @ethogram/cli and ethogram binary
├── docs/
│   ├── quickstart.md
│   ├── existing-agent.md
│   ├── execution-evidence.md
│   ├── packages.md
│   └── limitations.md
├── examples/
│   └── existing-agent/       # only after package scope is final; release-tested
├── internal/
│   └── baseline-preview/     # relocated root prototype/harness, if still needed
├── tests/                    # executable baseline plus frozen 01–09 records
├── LICENSE
└── README.md
```

Relocating the prototype must be a reviewed mechanical change with all Tests 01–09 passing; it is not part of the current release-preparation edits.

## Proposed deletions — not performed

- `components/ui/button.tsx`: unused shadcn component.
- `lib/utils.ts`: used only by the unused button component.
- `components.json`: shadcn scaffold metadata with no active component consumer.
- `public/placeholder-logo.png`, `public/placeholder-logo.svg`, `public/placeholder-user.jpg`, `public/placeholder.jpg`, and `public/placeholder.svg`: unused generic placeholder assets.
- `pnpm-lock.yaml`: candidate only after npm is formally selected as the sole package manager and CI/release instructions agree.

Do not delete the root prototype, `lib/agentbook/`, `stories/`, or any Test 01–09 material during cleanup review. The current executable baseline still depends on them.
